# Поклик Ктулху · Cloudflare

Оригінальний інтерфейс порталу перенесено із ZIP: листи дослідників, дошка, матеріали, нотатки, чати, кидки, музика, правила та теми.

- Сайт: https://cthulhugenius.technobio-portalworkersdev.workers.dev/migration/
- `google-auth.mjs` — чинний Google OAuth, без змін.
- `rooms.mjs` — чинні кімнати, учасники та старі чати/карти.
- `migration-store.mjs` — API перенесеного інтерфейсу з перевіркою доступу.
- `public/migration/index.html` — оригінальний інтерфейс.
- `public/migration-client.js` — адаптер Google/D1 замість Supabase.

## Дані та розгортання

Прив’язка D1, ідентифікатор бази, секрети Google та URI перенаправлення збережені. API створює лише нові таблиці `migration_records` і `migration_file_chunks` через CREATE TABLE IF NOT EXISTS. Повторно виконувати `schema.sql` не потрібно. Наявні акаунти, ролі, кімнати, учасники, повідомлення і карти читаються з поточної бази. Старі повідомлення доступні в чаті, стара карта стає карткою дошки до першого редагування.

Листи, матеріали, нотатки, правила і дошка зберігаються в D1. Файли до 25 МБ зберігаються частинами; один матеріал/стан дошки обмежено 1,9 МБ. Синхронізація через опитування кожні 3,5 секунди. Обмеження доступу застосовуються на сервері; приховані матеріали і приватні кидки не надсилаються стороннім гравцям.

ZIP не містив даних сесій, матеріалів та акаунтів старого Supabase. Ці дані не імпортуються автоматично; дані чинної D1 залишаються на місці. Локальні чернетки попереднього тестового інтерфейсу лишаються в браузері.

Cloudflare Builds: deploy command `npx wrangler deploy`; наявні налаштування не змінюються.

## Перевірка

Node.js 24+: `npm test`. Перевіряє Google cookie, права, приватні дані, листи, чат, кидки і сумісність з D1.
`npm run dev -- --port 4173` запускає ізольований локальний сервер із тестовим адміністратором та базою в пам’яті; він не входить у Worker і не підключається до справжньої D1.

## Кабінет адміністратора (оновлення 95)

`/migration/admin/` — окрема сторінка для керування всіма кімнатами, листами, ролями, запитами ведучих, цитатами, правилами та зверненнями. Адміністратор визначається за відбитком підтвердженої Google-пошти в `site-account.mjs`; призначити іншого адміністратора через клієнтський API неможливо. Права надаються також для вже відкритої сесії після оновлення сторінки. Адміністратор переходить із кабінету до повного ігрового столу, де доступні оригінальні інструменти ведучого. Призначення адміністратора не змінює власників наявних пригод.

Нові кімнати мають короткі коди `CTH-A8DA`; старі коди з 20 символів продовжують працювати. Приєднання обмежене десятьма спробами за хвилину для одного акаунта. Облікові записи, активні сесії, існуючі кімнати та матеріали не очищаються. Вхід залишається через Google; відновлено вибір теми на екрані входу та розміри тексту оригінального інтерфейсу. Повідомлення про помилки зберігаються в D1 та доступні в кабінеті адміністратора.

## Структуровані матеріали (оновлення 97)

Центральну дошку замінено на бібліотеку вертикальних карток. Категорії можуть містити інші категорії та кінцеві картки з описом, зображенням і файлом із бібліотеки пригоди. Редактор підтримує кадрування обкладинки, масштабування, перетягування, базове форматування опису та доступ «приховано / всім / обраним». Переставлення й видалення доступні ведучому через налаштування поточної вкладки.

Дані зберігаються в D1: `room_material_cards` та `room_material_versions`. Права перевіряються на сервері для всього ланцюжка батьківських категорій, зокрема під час доступу до прикріплених файлів. Зміни синхронізуються під час відкритої кімнати приблизно кожні 3,5 секунди. Перевірка версій не дозволяє непомітно перезаписати новішу редакцію картки. Пагінація відображає по 48 карток; вкладеність — до 12 рівнів. Вбудовані зображення обробляються браузером до збереження.

На порожній бібліотеці є кнопка перенесення старих матеріалів. Вона створює приховану вкладку «Матеріали до оновлення» і копіює попередні матеріали та карти, включно з PDF. Початкові записи залишаються в базі. Для відкриття скопійованих матеріалів гравцям потрібно налаштувати доступ до цієї вкладки та потрібних дочірніх карток.

Додано шрифти Volja, Irpin Type і Epoch DEMO (для заголовків), вибір яких зберігається в браузері. У `public/fonts/epoch-license.txt` збережено ліцензійну примітку автора DEMO: для особистих проєктів. Favicon створено з наданого власником зображення без зміни малюнка. Файли шрифтів і значка зберігаються разом із кодом, а завантажені користувачами матеріали — у D1.
